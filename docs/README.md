# ReMedX Documentation & Research Directory

This directory contains research literature, system architecture blueprints, pitch decks, and technical proposals backing the **ReMedX** AI Drug Repurposing Platform.

---

## Directory Organization

### 1. [`proposal/`](./proposal/)
- **`ReMedX_Proposal.pdf`**: The original foundational proposal document defining the motivation, biomedical challenge, proposed workflow, and project milestones.

### 2. [`presentation/`](./presentation/)
- **`Presentation.docx`**: Core presentation deck draft detailing the problem, solution, validation, and market viability.
- **`ReMedX_Presentation_Slides_Additions.docx` & `.md`**: Pitch slide outlines, speaker notes, and demonstration walkthroughs.

### 3. [`research/`](./research/)
- **`research&enhancement.md`**: Comprehensive deep-dive covering Open Targets GraphQL integration, ChEMBL REST endpoints, Reactome pathway analysis, cheminformatics equations (Lipinski, Veber, Ghose, QED, Brenk, PAINS), and multi-threading architecture.
- **`research2.md`**: Extended biomedical reference material, edge cases, and therapeutic validation datasets.
- **`prompt.md`**: Architectural guidelines, engineering constraints, and system specifications.

### 4. [`media/`](./media/)
- **`architecture_mindmap.png`**: Visual system map depicting multi-source data ingestion, AI processing layers, and clinical output pipelines.
- **`pipeline_workflow.jpeg`**: Workflow diagram detailing target validation and chemical filtering steps.
